# KTP 회고: 리팩토링 작업 (Refactoring Sprint)

**작업 기간**: 리팩토링 스프린트  
**작업 범위**: 코드 구조 개선, 매직넘버 상수화, 중복 제거, 타입힌트 추가

---

## 📌 Keep (잘한 점)

### 1. **체계적인 리팩토링 접근**
- 동작 변경 없이 구조만 개선하는 원칙을 명확히 설정
- 매직넘버 상수화 → 타입힌트 추가 → 중복 제거 → 함수 Rename 순서로 단계적 진행
- 각 단계마다 린터 검사 및 테스트 호환성 확인

### 2. **중복 코드 제거를 위한 헬퍼 함수 도입**
- `_rank_by_metric()` 함수로 gainers/losers/volatile 랭킹 로직 통합
- `_render_ranking_table()` 함수로 UI 테이블 렌더링 중복 제거
- DRY 원칙 준수로 유지보수성 향상

### 3. **매직넘버 상수화로 유연성 확보**
- `rank_movers()` 함수에 `top_n` 파라미터 추가
- `DEFAULT_TOP_N` 상수를 기본값으로 사용
- 하드코딩된 `.head(10)` 제거로 확장성 개선

### 4. **타입힌트 일관성 유지**
- 모든 공개 함수에 타입힌트 추가
- 내부 헬퍼 함수에도 타입힌트 적용
- `# type: ignore[type-arg]` 주석으로 mypy 호환성 유지

### 5. **기존 테스트 호환성 보장**
- 기본값(`DEFAULT_TOP_N = 10`) 유지로 기존 테스트 무변경
- 함수 시그니처 변경 시 하위 호환성 고려
- 리팩토링 후에도 동작 변경 없음을 확인

## ⚠️ Problem (문제점/막혔던 점)

### 1. **환경 의존성으로 인한 테스트 실행 실패**
**문제**: `pytest` 실행 시 `ModuleNotFoundError: No module named 'pandas'` 발생  
**원인**: 
- 로컬 환경에 필요한 패키지 미설치
- 가상환경 활성화 누락
- `requirements-dev.txt` 설치 누락

**재발 방지**:
- `README.md`에 환경 설정 가이드 명시
- `pytest` 실행 전 의존성 체크 스크립트 추가
- CI/CD 파이프라인에서 자동 테스트 실행

### 2. **타입힌트 추가 시 mypy 호환성 이슈**
**문제**: `DataFrame` 타입에 대한 제네릭 타입 인식 문제  
**원인**:
- pandas의 `DataFrame`이 제네릭 타입이 아니어서 mypy가 타입 체크 실패
- `typing` 모듈의 `DataFrame` 타입 힌트 한계

**재발 방지**:
- `# type: ignore[type-arg]` 주석으로 명시적 처리
- 타입 체크 규칙을 `pyproject.toml`에 문서화
- 타입 힌트 가이드라인 작성

### 3. **중복 코드 패턴 인식 지연**
**문제**: UI 테이블 렌더링 코드가 5곳에서 반복됨  
**원인**:
- 리팩토링 초기 단계에서 전체 코드 구조 파악 부족
- 중복 패턴을 찾기 위한 체계적 분석 부재

**재발 방지**:
- 리팩토링 전 코드베이스 전체 검토
- 중복 코드 탐지 도구 사용 (`pylint`, `vulture`)
- 코드 리뷰 체크리스트에 중복 검사 항목 추가

### 4. **함수 시그니처 변경 시 호출부 업데이트 누락 위험**
**문제**: `rank_movers()`에 `top_n` 파라미터 추가 시 모든 호출부 확인 필요  
**원인**:
- 함수 사용처를 수동으로 검색해야 함
- IDE의 자동 리팩토링 기능 미활용

**재발 방지**:
- `grep` 또는 IDE의 "Find Usages" 기능 활용
- 함수 시그니처 변경 시 모든 호출부 자동 검색
- 변경 사항을 TODO 리스트로 관리

### 5. **매직넘버 식별의 주관성**
**문제**: 어떤 숫자가 매직넘버인지 판단 기준이 모호함  
**원인**:
- 명확한 매직넘버 정의 기준 부재
- 상수화 우선순위 불명확

**재발 방지**:
- 매직넘버 정의 기준 문서화 (예: 하드코딩된 숫자, 반복 사용되는 값)
- 코드 리뷰 체크리스트에 매직넘버 검사 항목 추가
- `config.py`에 상수 정의 가이드라인 작성
